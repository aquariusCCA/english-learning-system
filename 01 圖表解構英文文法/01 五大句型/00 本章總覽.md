# 本章總覽　五大句型

> [!IMPORTANT]
> **一句話核心**
> 所有英文句子都是這五種基本結構的變化——先分清動詞是「及物／不及物」，再看它需不需要「補語」。

## 📊 五大句型公式

| # | 句型公式 |
| --- | --- |
| 1 | S. + Vi. |
| 2 | S. + Vi. + S.C. |
| 3 | S. + Vt. + O. |
| 4 | S. + Vt. + I.O. + D.O. |
| 5 | S. + Vt. + O. + O.C. |

## 🔤 詞性縮寫對照

> 這五種句型，分別由以下的要素組成。

| 英文縮寫 | 詞性 | 說明 |
| --- | --- | --- |
| S. | 主詞 | 指「你、我、他、你們、我們、他們、它、它們」 |
| Vi. | 不及物動詞 | i 表示 intransitive，指「不及物」，亦指動詞本身可表達完整的語意，不需要接補語 |
| Vt. | 及物動詞 | t 表示 transitive，指「及物」，亦指此類動詞之後需接受詞，才能表達完整的語意 |
| S.C. | 主詞補語 | 補語是補述說明，主詞補語就是補充說明主詞的狀態，通常是名詞、形容詞 |
| O.C. | 受詞補語 | 受詞補語就是補充說明受詞的狀態或性質，可用名詞、形容詞、現在分詞、過去分詞、原形動詞、不定詞、地方副詞片語等作補語 |
| O. | 受詞 | 可以是東西或是人，通常是名詞、動名詞、不定詞等 |
| I.O. | 間接受詞 | 間接受詞通常是人 |
| D.O. | 直接受詞 | 直接受詞通常是事物 |

## 📋 重點整理：五大句型動詞分類
> 從動詞的分類回看五大句型。

| 動詞大類 | 細分 | 句型 |
| --- | --- | --- |
| ❶ 不及物動詞（Vi.） | 完全不及物動詞 | S. + Vi. |
| | 不完全不及物動詞 | S. + Vi. + S.C. |
| ❷ 及物動詞（Vt.） | 完全及物動詞 | S. + Vt. + O. |
| | 授與動詞 | S. + Vt. + I.O. + D.O. |
| | 不完全及物動詞 | S. + Vt. + O. + O.C. |

## ✏️ 例句

| 句型 | 英文例句 | 中文翻譯 |
| --- | --- | --- |
| S. + Vi. | She smiled. | 她笑了。 |
| S. + Vi. + S.C. | He is a good teacher. | 他是好老師。 |
| S. + Vt. + O. | I love you so much. | 我很愛你。 |
| S. + Vt. + I.O. + D.O. | He shows me his new wallet. | 他給我看他的新皮夾。 |
| S. + Vt. + O. + O.C. | The gifts make me very happy. | 這些禮物讓我很開心。 |

## 🧠 自我測試（書中前測）

> 先來連連看以下句子，看看你對句型的結構了解了多少？把下列句子連到對應的句型。

- [ ] He is a good teacher.
- [ ] She smiled.
- [ ] He shows me his new wallet.
- [ ] I love you so much.
- [ ] The gifts make me very happy.

句型選項：`1. S. + Vi.`／`2. S. + Vi. + S.C.`／`3. S. + Vt. + O.`／`4. S. + Vt. + I.O. + D.O.`／`5. S. + Vt. + O. + O.C.`

<details>
<summary>✅ 解答</summary>

- She smiled. → **1. S. + Vi.**
- He is a good teacher. → **2. S. + Vi. + S.C.**
- I love you so much. → **3. S. + Vt. + O.**
- He shows me his new wallet. → **4. S. + Vt. + I.O. + D.O.**
- The gifts make me very happy. → **5. S. + Vt. + O. + O.C.**

</details>
